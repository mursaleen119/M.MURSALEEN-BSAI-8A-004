# Week 3 solution

Dataset: [`../data/gapminder.csv`](../data/gapminder.csv). Task-specific dataset differences are noted in the notebook; no other source dataset is added.

Notebook: [`weak-3_solution.ipynb`](weak-3_solution.ipynb)

## Tasks

1. **Task 1 — Nine chart diagnoses** — Nine original case datasets are replaced with measurable Gapminder chart decisions; limitations and redesigns are recorded.
2. **Task 2 — Lie Factor** — Where a comparable geometric encoding exists, the calculation is shown; cases with no comparable baseline are identified.
3. **Task 3 — Palette audit** — The palette is simulated for common colour-vision deficiencies and measured for close pairs.
4. **Task 4 — Review figure** — A multi-panel country-year review figure is built with labeled units and no dual axes.
5. **Task 5 — Written justification** — The design choices and the limits of adapting clinical variables to Gapminder are stated.

## Charts and files

Figures and audit artifacts are saved under [`charts/`](charts/). Human-participant tasks are not marked complete until real responses are collected.
