# Weak Two

This task is based on the official Week 2 visual-perception brief from the reference course repository.

## Dataset used

The easy dataset used here is `tips.csv`, which is the simplest dataset in the brief and is well suited for Week 2 cognitive-load and data-ink work.

## Goal

- build a deliberately overloaded chart labeled `BAD EXAMPLE`
- identify the extraneous visual elements and explain the resulting cognitive load
- remove clutter step by step
- create a cleaner final chart
- explain why the simplified version is easier to interpret
