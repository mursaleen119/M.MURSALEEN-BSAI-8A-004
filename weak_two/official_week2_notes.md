# Official Week 2 task notes

This repository follows the Week 2 visual-perception ideas from the reference course repository:

https://github.com/UsmarHaider/data-visualization

## Chosen dataset

The easiest dataset in the Week 2 assignment set is `tips.csv`.

It is used here because it is simple, readable, and well suited for demonstrating:

- cognitive load
- clutter reduction
- data-ink ratio
- readability improvements

## Assignment intent

The official Week 2 brief asks students to investigate how the human brain processes visual information and then design charts accordingly.

The key ideas are:

1. reduce extraneous load
2. keep the title focused on the finding
3. remove decoration that does not carry data
4. use one clear message instead of many competing visual cues
5. improve readability without hiding the pattern

## Task structure used here

This repo implements the easiest and most direct part of the official assignment:

- build a deliberately overloaded chart labeled `BAD EXAMPLE`
- explain the causes of visual clutter
- remove the clutter in stages
- produce a simplified and cleaner chart
- explain why the cleaner version is easier to read
