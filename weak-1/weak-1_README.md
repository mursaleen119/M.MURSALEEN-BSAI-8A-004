# Week 1 ? Official assignment deliverables

Five separate, reproducible notebooks follow the instructor tasks and use the required datasets: `task1.ipynb` through `task5.ipynb`. Run them from this folder in Jupyter. The common implementation lives in `assignments/week1_assignment.py`; charts and computed tables are kept in `charts/`.

Official brief: https://github.com/UsmarHaider/data-visualization/blob/main/week1/assignments/TASKS.md
Course README: https://github.com/UsmarHaider/data-visualization/blob/main/week1/README.md

Input CSVs are fetched by `assignments/download_assignment_data.py` into `assignments/data/`. The scoped `assignments/data/.gitignore` keeps raw datasets as local caches, not repository deliverables.
