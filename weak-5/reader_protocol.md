# Week 5 reader protocol

The original task asks for five readers to compare crime-count and crime-rate maps. Gapminder has no crime counts or boundary geometry, so I did not create maps or reader results.

For a clearly labelled substitute, show the two continent comparison panels in `week5_task02_count_vs_rate.png` to five real readers. Ask each person to name the largest three categories in each panel, without letting them revise the first answer. Record the two answers and their overlap. This tests how a denominator changes a comparison; it is not evidence about geographic crime patterns.
