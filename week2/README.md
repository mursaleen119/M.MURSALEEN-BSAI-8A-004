# Week 2 — Weak Two task

This folder contains the simplified Week 2 visual-perception task built from the easiest dataset in the assignment set: `tips.csv`.

## Task focus

The official Week 2 idea is about cognitive load and data-ink ratio. The task asks the student to:

1. create a deliberately overloaded chart (`BAD EXAMPLE`)
2. identify the visual clutter and explain the source of extra load
3. remove unnecessary elements step by step
4. produce a cleaner final chart
5. explain why the cleaner version is easier to interpret

## This repository contains

- a bad example chart
- a five-step de-cluttering figure
- a clean final chart
- a written explanation of the design choices
