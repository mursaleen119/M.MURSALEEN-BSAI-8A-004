# Week 2 — Visual Perception

This folder documents the official Week 2 task and the simplified weak-two task implementation in this repository.

## Official assignment idea

Datasets and assignments for Week 2: preattentive attributes, Gestalt principles, and cognitive load.

**CLO1 — Identify how the human brain processes visual information.**

The official Week 2 goal is to reduce cognitive load and improve the data-ink ratio by:

- creating a deliberately overloaded chart labeled `BAD EXAMPLE`
- identifying the visual clutter and extra load
- removing unnecessary elements step by step
- producing a cleaner final chart
- explaining why the cleaner result is easier to interpret

## This repository contains

- a bad example chart
- a five-step de-cluttering figure
- a clean final chart
- a written explanation of the design choices
