Dataset: [`../data/gapminder.csv`](../data/gapminder.csv). Task-specific dataset differences are noted in the notebook; no other source dataset is added.

## Tasks

1. **Task 1 — Audit the source** — Gapminder's actual keys, missingness, sentinels, date coverage and ranges are audited without modifying the sole source file.
2. **Task 2 — Three chart questions** — A trend, a composition comparison and a relationship are answered in a single figure.
3. **Task 3 — Board figure** — A public-health audience sees how life expectancy changed across continents; it is not an electricity-grid claim.
4. **Task 4 — Bonus interaction** — A local HTML chart supports filtering by continent and hovering over year-level values.
